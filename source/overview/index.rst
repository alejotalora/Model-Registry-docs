What is the Model Registry?
===========================

The Model Registry is a core component of the STAMM platform responsible
for managing machine learning models, their metadata and artifacts, and
providing access through a REST API.

It acts as the central service for model management within the platform.

Architecture
------------

The Model Registry architecture describes the main application containers,
their internal components, communication paths, and storage mechanisms.

The architecture is documented using a C4 Container Diagram (Level 2),
which provides a high-level view of the main runtime components and their
relationships.
